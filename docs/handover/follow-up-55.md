## Dated-record errata

These passages remain unchanged:

- `docs/ROADMAP.md`, [“Task board”](../ROADMAP.md#task-board), the done row `w2-agent-core follow-up 15`: the row still says twelve consecutive failed `conntrack -D` attempts, or a missing binary, fail isolation closed, and that the count persists across restarts. The current bound is twelve durably reserved serving-Apply delete batches (`maxConntrackDeleteAttempts`). The reservation is stored before Apply. A crash or an earlier failure consumes a reservation. A missing `conntrack` binary does not use this count; `LookPath` fails closed at once. See [desired state and leases](../node/README.md#desired-state-and-leases-147-163).
