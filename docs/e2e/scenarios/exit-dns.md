# Exit-traversing DNS and IPv6 boundary

`exit-dns` queries the applied designated resolver over TCP and UDP 53.
The resolver lives on the isolated origin network and forwards to the node's
filtering AdGuard. Both `nu_` and `nd_` must increase for the admitted device;
`u_` and `d_` must remain unchanged. Response metadata is retained, query names
and packet contents are not. Native DNS fallback remains outside this proof.

`member-ipv6` records the configured native IPv6 mode and stays blocked until
a dual-stack underlay/native route and platform capture matrix exists. Merely
finding an IPv6 address is not a pass. This row names the AT11 backlog honestly.
