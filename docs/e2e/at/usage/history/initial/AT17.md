## Expected (§19)

Cross-month intervals are split at 00:00:00Z into single-month UsageEvents; late-arriving previous-month events within the 24h watermark attribute strictly to the previous UTC month; wall-clock rollback >5s emits a clock_rollback gap and never produces negative intervals or negative byte deltas.

## Actual

Live GET /api/v1/member/usage verified half-open UTC month intervals and query validation, and central/node mechanisms verified 00:00:00Z month-boundary splitting, late-arriving previous-month attribution, and clock rollback protection. End-to-end member traffic across a month rollover on the live stack is blocked because node publication returns HTTP 422 NODE_NOT_SERVICEABLE and device_bindings=0.
