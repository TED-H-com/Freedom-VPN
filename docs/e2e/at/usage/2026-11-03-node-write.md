# 2026-11-03 — `Stack.WriteNode` Adoption and Node-Write Audit (Follow-up 9)

This note records the offline adoption of `e2e.Stack.WriteNode` (`tests/e2e/node_write.go`, exposed through `tests/e2e/stack_exports.go`) across `tests/e2e/at/usage/`, answering the devstack 32 / 33 hand-off in [`docs/e2e/RESPONSES.md`](../../RESPONSES.md#devstack--2026-11-03-follow-up-32).

## 1. Summary

- Every node write in `tests/e2e/at/usage/` routes through `(*liveSuite).nodeMutation`, which now delegates to `s.hook.WriteNode` (`(*e2e.Stack).WriteNode`) with an initial `GET /api/v1/admin/nodes/{id}` ETag read and a command-specific `intended` read-back predicate derived by `nodeMutationPredicate(method, suffix, body)`.
- If the initial `GET /api/v1/admin/nodes/{id}` does not return `200 OK`, `nodeMutation` passes `intended = nil` so `WriteNode` fails closed before issuing a blind write without `If-Match`.
- If `nodeMutationPredicate` receives an unknown `(method, suffix)` or a body missing required command fields, it returns `nil` and `WriteNode` refuses before sending the request.
- Every `nodeMutation` call returns a `nodeCommand` carrying its `e2e.NodeWriteReceipt` (`WriteEvidence()`) and appends the receipt to `s.nodeWriteReceipts` (surfaced in `rec.Observations["node_writes"]` on every `AT14`–`AT19` record, and in specific check details and top-level observation fields where individual node writes are exercised).
- Observed-state checks after every node write remain intact: HTTP `200`/`202` command acceptance is never treated as applied-state completion. When `POST /api/v1/admin/nodes/{id}/revoke` reconciles via `412 RESOURCE_VERSION_CONFLICT` with `AlreadyIntended: true` (the prior attempt already committed `lifecycle_state == "revoked"`), the callers (`measurePerIncarnationRetainedUsage` and `evalAT20`) look up the real `node.revoke` operation from `operations WHERE target_type='node' AND target_id=$1 AND kind='node.revoke'` rather than fabricating an operation or skipping operation/incarnation read-back.
- Live proof on the assembled lab stack waits for the next authorized assembled run. Committed run `b8a6e9e1` records (`AT14.json`–`AT20.json`, `AT14.md`–`AT20.md`, `README.md`, `RUN.md`, `summary.md`, `operator-run.md`, `history/**`) are untouched.

## 3. AST Audit and Exceptions (`tests/e2e/at/usage/node_write_audit_test.go`)

`TestNodeWriteAudit` parses every `*.go` file in `tests/e2e/at/usage/` (regardless of build tags, so it runs under default `go test ./tests/e2e/at/usage` as well as `-tags e2e`) and flags:
1. Any string literal containing `/admin/nodes` outside `nodeWriteAuditAllowedFiles` (`live_test.go`, `live_helpers_test.go`, `live_handoff_test.go`, `node_write_test.go`, `node_write_audit_test.go`), or any string literal containing `/admin/nodes` inside those files that is used with a mutating HTTP method (`POST`, `PUT`, `PATCH`, `DELETE`) outside `liveSuite.nodeMutation` or `node_write_test.go`.
2. Any call to `adminJSON`, `memberJSON`, `sessionJSON`, `rawNodeMTLSRequest`, `http.NewRequest`, `http.NewRequestWithContext`, or `Client.Do` outside its documented dispatch boundary.

### Documented Dispatch Boundaries in `nodeWriteAuditExceptions`

Zero node-write calls bypass `(*liveSuite).nodeMutation` -> `s.hook.WriteNode`. The only sites in `nodeWriteAuditExceptions` are the single-point helper boundaries or non-node requests:

1. `live_test.go:liveSuite.nodeMutation` — Single node-write entry point for the usage AT suite; reads the current ETag via `GET /api/v1/admin/nodes/{id}` and delegates the write to `s.hook.WriteNode` with `nodeMutationPredicate(method, suffix, body)`.
2. `live_test.go:liveSuite.adminJSON` — Generic admin JSON helper implementation (dispatches through `s.sessionJSON`); AST audit verifies no `/admin/nodes` write path ever reaches `adminJSON`.
3. `live_test.go:liveSuite.memberJSON` — Member API JSON helper implementation (`/api/v1/me/...`, never `/admin/nodes`).
4. `live_test.go:liveSuite.sessionJSON` — Low-level cookie+CSRF request dispatcher used by `adminJSON`/`memberJSON` and passed into `s.hook.WriteNode` via `s.adminHook()`.
5. `live_helpers_test.go:liveSuite.rawNodeMTLSRequest` — Node mTLS data-plane helper (`/api/v1/node/...`: heartbeats, observations, usage batches, leases; never `/api/v1/admin/nodes`).
6. `live_test.go:liveSuite.adminHook` — Closure adapter converting `s.sessionJSON` into the `func(ctx, method, path, body, headers)` signature required by `s.hook.WriteNode`.
7. `node_write_test.go:TestNodeWrite_SharedHelperConflictPathsAndReceipts` — Offline unit test exercising `(*e2e.Stack).WriteNode` directly against deterministic conflict and reconciliation stubs.

`TestNodeWriteAuditRejectsBypasses` injects three synthetic bypass files into the audit (`adminJSON` `PATCH /api/v1/admin/nodes/{id}`, `sessionJSON` `POST /api/v1/admin/nodes/{id}/revoke` via a variable path, and `http.NewRequestWithContext` `DELETE /api/v1/admin/nodes/{id}`) and verifies that `auditUsageDir` rejects each one.

## 4. Offline Verification Tests (`tests/e2e/at/usage/node_write_test.go`)

- `TestNodeWrite_AdoptedCallShapesAndPredicates`: verifies every adopted command shape in `tests/e2e/at/usage/` (`PATCH ""` capacity, `PUT "/publication"` published and disabled with non-empty or empty `group_ids`, `POST "/revoke"`, `DELETE ""` retire) accepts only a read-back document whose fields all match, and rejects mismatched fields, partial fields, extra/missing groups, empty reasons, or unknown routes.
- `TestNodeWrite_SharedHelperConflictPathsAndReceipts`: exercises `(*e2e.Stack).WriteNode` across all 4 command families for:
  - `412 RESOURCE_VERSION_CONFLICT` followed by fresh `GET` (`intended == false`) and a `200`/`202` retry carrying the refreshed ETag (`Attempts == 2`, `Retried == true`, `AlreadyIntended == false`).
  - `412 RESOURCE_VERSION_CONFLICT` where the concurrent state already satisfies `intended(readBackBody) == true` (`Attempts == 1`, `AlreadyIntended == true`, no duplicate write sent, `accepted(http.StatusOK, http.StatusAccepted) == true`).
  - `412 RESOURCE_VERSION_CONFLICT` where `intended(readBackBody) == false` on all 3 attempts (`Exhausted == true`, `accepted(...) == false`).
  - Non-retryable `412 PRECONDITION_REQUIRED` (`Attempts == 1`, no retry, `accepted(...) == false`).
  - Initial `GET /api/v1/admin/nodes/{id}` failure (`503`): `nodeMutation` passes `intended = nil` and `WriteNode` fails closed with `Attempts == 0` without sending a blind write.
