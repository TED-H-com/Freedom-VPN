# Project Spec

`PROJECT_SPEC.zh-TW.md` is the Project Spec v1.0 (dated 2026-10-28), converted from the original Word document. The conversion keeps all text, tables and code blocks. The only figure is `architecture-figure-1.png`.

This spec is the product and engineering contract for this repository. Code, tests and docs cite it as `§<chapter>.<section>`. Requirement IDs (for example `MTR03`) come from §4 and acceptance cases (`AT01` to `AT32`) from §19.

When a newer spec version is approved, it replaces this file in a dedicated commit. Until then, this version wins over any other description.
