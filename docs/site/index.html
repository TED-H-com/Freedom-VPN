開源會員制 VPN 管理平台

以自己的節點，
管理會員 VPN。

Freedom VPN 以自架 NetBird 與官方 App 為基礎，讓不同地點的 Ubuntu 出口節點，共用一套會員、用量、政策與維運流程。

同一套平台，三種日常工作

會員

登入與管理裝置、查看資格及用量，再於官方 App 手動選擇已授權出口。

管理員

管理會員與出口節點，追蹤上架、撤權和非同步操作的實際結果。

維運者

部署中央服務與節點，執行簽章更新，依操作手冊完成備份及還原。

現有實作範圍

到維護每一個出口。

會員的連線方式

使用 NetBird 官方 App。

會員入口負責帳戶與裝置；VPN 連線與出口選擇由官方 App 處理。本專案不提供自有品牌客戶端。

  1. 確認會員資格

    登入會員入口，確認方案、裝置額度與可使用的出口。

  2. 連至自架管理服務

    依會員指南設定 NetBird management URL，使用同一個 OIDC 身分登入。

  3. 選擇已授權出口

    完成裝置授權後，在官方 App 手動選擇出口；用量與公平使用狀態回到會員入口查看。

現況與驗證

功能存在，
不代表已完成正式驗收。

Freedom VPN 目前是開發與驗證版本。請以交付導覽與各項驗收紀錄為準；此頁不宣告正式發行或全面平台支援。

實機與網路

Windows、macOS、Android、iOS，以及實體 arm64、候選硬體容量與部分隔離／故障場景仍有驗證缺口。

會員裝置保護

伺服器端 Internet-only 隔離不提供作業系統 kill switch；隧道中斷時，不能保證裝置不使用原本 ISP。

正式環境設定

正式 IdP / MFA、付款供應商、網域 / TLS、DNS 清單及營運參數，仍需個別設定與驗證。
